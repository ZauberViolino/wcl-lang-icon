# wcl-lang-icon

Batch generate language icons in the style of Wikimedia Community Logo. See [ZauberViolino/wcl-lang-icon-js](https://github.com/ZauberViolino/wcl-lang-icon-js) for an HTML one-at-a-time generator.

The icon style was first designed by [Winston Sung](https://github.com/winstonsung) in [Wikimedia-nan](https://t.me/Wikimedia_nan).

Fonts are all copied, SIL OFL 1.1.

Python scripts are vibe-coded.
